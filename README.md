Application Setup and User Experience Documentation
Step 1: Run the Application
To start the application, open your terminal and run the following command:

npm start

Step 2: Accessing the Application
Once the application is running, open your web browser and navigate to:

http://localhost:3000

You will be directed to the home page of the application.

Step 3: Creating an Account and Logging In
Creating an Account
If you don’t have an account, create a new account by providing the necessary details.
